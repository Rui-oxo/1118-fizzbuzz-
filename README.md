# FizzBuzz Viewer (1〜50)

1から50までの数値を判定し、カード形式でモダンに可視化する FizzBuzz Web アプリケーションです。

## 概要

このプロジェクトは、プログラミングの古典的な課題である「FizzBuzz」をブラウザ上で視覚的・直感的に確認できるようにした Web ページです。

### FizzBuzz のルール
- **3 の倍数**: `Fizz` と表示
- **5 の倍数**: `Buzz` と表示
- **3 と 5 の公倍数（15 の倍数）**: `FizzBuzz` と表示
- **その他の数値**: そのままの数値を表示

---

## 主な特徴

- 🎨 **モダンなカード＆グリッド UI**:
  レスポンシブ対応の CSS Grid を採用し、デバイスの画面サイズに応じてカードが綺麗に整列します。
- 🌈 **ステータス別カラーリング**:
  - **Fizz (3の倍数)**: スカイブルー
  - **Buzz (5の倍数)**: エメラルドグリーン
  - **FizzBuzz (15の倍数)**: パープル〜ピンクのグラデーション
  - **通常**: クリーンなグレー
- 💡 **直感的な情報表示**:
  各カードに元の数値（`#15` など）と結果ラベル（`FizzBuzz` など）を併記し、上部には凡例を備えています。
- ⚡ **1ファイル完結**:
  HTML・CSS・JavaScript を `index.html` の1ファイルに内包しており、外部ライブラリやビルドツール不要で即座に動作します。

---

## 使い方

特別なセットアップやサーバーの立ち上げは不要です。

1. 本リポジトリをクローンまたはダウンロードします。
2. `index.html` を任意の Web ブラウザ（Chrome、Edge、Safari、Firefox など）で直接ダブルクリックして開きます。
